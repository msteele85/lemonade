# Lemonade — Project Instructions

## Required Reading

Before any agentic work (code changes, agent prompts, feature design, architecture decisions), always read and follow:

1. **MANIFESTO.md** — The product manifesto and six guiding principles. Every product decision, agent prompt, and line of code must align with it.
2. **core_principles.md** — Core rules for all agents: easy UX, safety-first privacy, fast time-to-value, entrepreneurship focus, no MLMs.

These documents govern all decisions in this project. If a proposed change conflicts with either document, the change must be revised to align.
